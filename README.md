# MyLedger

**ניהול כסף לפי תזרים, על המחשב שלכם.** MyLedger מושך את התנועות מהבנק ומכרטיסי האשראי בישראל, מסווג אותן, ועונה על השאלה שבאמת חשובה באמצע החודש: **כמה נשאר לי להוציא — ומה עוד צפוי לרדת?**

בלי חשבון משתמש בשירות ובלי מנוי. הנתונים נשמרים במחשב שלכם; סיסמאות הבנק מוצפנות ב-Windows DPAPI והגיבויים מוצפנים בסיסמה נפרדת. מסד הנתונים הפעיל אינו מוצפן ברמת הקובץ. סיכומים נשלחים לטלגרם רק אם הפעלתם זאת.

<p align="center"><img src="docs/images/home.png" alt="המסך הראשי של MyLedger" width="820"></p>

> *English summary:* MyLedger is a self-hosted, privacy-first personal finance app for Israeli banks and credit cards. It scrapes transactions locally with [israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers), stores them in SQLite, and answers "how much can I still spend this month" with a cash-flow model (fixed vs. variable, credit-card float, instalments). Hebrew RTL UI, Windows (DPAPI) for credential encryption. See [docs/INSTALL.md](docs/INSTALL.md).

## למה עוד אפליקציה לכסף?

רוב הכלים מסדרים את העבר: "הוצאת 2,400 ₪ על סופר". MyLedger בנוי להחלטות של היום:

- **תחזית לסוף המחזור** — הכנסות שעוד צפויות, הוצאות קבועות שעוד לא ירדו, וקצב ההוצאה הרגיל שלכם. לא רק מה כבר קרה.
- **קבוע מול משתנה** — שכר דירה, ביטוחים ומנויים מזוהים אוטומטית ויורדים מראש. מה שנשאר הוא הכסף שבאמת בשליטתכם.
- **חיובי אשראי שעוד לא ירדו** — קניות שכבר נעשו ועוד לא ירדו מהבנק. זו הסיבה שיתרת הבנק מחמיאה לכם, והמערכת מראה אותם במפורש.
- **בלי ספירה כפולה** — חיוב האשראי המרוכז בבנק והקניות בכרטיס הם אותו כסף. המערכת מזהה ומתאימה ביניהם, גם כשכל בנק מנסח את החיוב אחרת.

## התחלה מהירה

דרישות: **Windows 10/11**. את Node.js המתקין בודק ומציע להתקין בעצמו.

1. **Code ← Download ZIP**, וחלצו לתיקייה קבועה.
2. לחיצה כפולה על **`install.cmd`** — מתקין, בונה, ופותח את המערכת בדפדפן.
3. בפעמים הבאות: **`start.cmd`**.

או ידנית, עם Git:

```powershell
git clone https://github.com/ilaykid/MyLedger.git
cd MyLedger
npm ci
npm run web:install
copy .env.example .env
npx prisma migrate deploy
npm run web:build
npm run seed        # אופציונלי: משק בית לדוגמה, כדי להסתכל לפני שמחברים משהו
npm run api         # ← http://127.0.0.1:3010
```

בלי נתוני דוגמה, המסך הראשון מוביל אתכם בחיבור הבנק, הכרטיסים ועדכון הנתונים הראשון.

📘 **[מדריך התקנה מלא](docs/INSTALL.md)** — חיבור חשבונות, התחברות עם SMS, הרצה אוטומטית יומית, גיבוי, טלגרם ופתרון תקלות.
📗 **[מדריך שימוש](docs/USER_GUIDE.md)** — כל מסך וכל פיצ'ר, המושגים שמאחוריהם ושגרת שימוש מומלצת.
🔧 **[ארכיטקטורה](docs/ARCHITECTURE.md)** — איך המנוע עובד ולמה.

## פרטיות ואבטחה

- **הכול מקומי.** מסד נתונים SQLite בתיקייה שלכם. הממשק מאזין ל-`127.0.0.1` בלבד.
- **סיסמאות מוצפנות** ב-Windows DPAPI לפני שהן נכתבות לדיסק, ולעולם לא נשלחות חזרה לדפדפן.
- **מוגן מאתרים זדוניים** שפתוחים בדפדפן: הגנת CSRF, בדיקת Host נגד DNS rebinding, ובלי CORS.
- **שום דבר לא יוצא** חוץ מעדכון הנתונים מהבנק עצמו, ומסיכומי טלגרם אם הפעלתם אותם.
- **תלויות נעולות** ו-`npm run secure:check` שבודק את כל ההנחות.

מומלץ מאוד לחבר **משתמש צפייה בלבד** בבנק. פרטים, מודל האיום ודיווח על חולשות: **[SECURITY.md](SECURITY.md)**.

## חשוב לדעת

- MyLedger **אינו קשור** לאף בנק או חברת כרטיסי אשראי, ואינו ייעוץ פיננסי. התחזיות הן הערכה.
- עדכון נתונים אוטומטי עשוי להיות מנוגד לתנאי השימוש של הבנק או של חברת האשראי. האחריות על השימוש היא שלכם.
- התמיכה בספקים מגיעה מ-[israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers); כשאתר של בנק משתנה, לפעמים צריך לחכות לעדכון שלה.
