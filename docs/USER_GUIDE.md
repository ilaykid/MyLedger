## חמישה מושגים שכדאי להכיר

**1. מחזור.** ברירת המחדל היא חודש קלנדרי רגיל. אם המשכורת נכנסת רחוק מה-1, אפשר לעגן את המחזור ליום המשכורת (למשל מה-9 עד ה-8) ב**הגדרות ← יום פתיחת המחזור**.

**2. סוג הכסף.** כל קטגוריה שייכת לאחד מהסוגים האלה, והסוג הוא שקובע את התחזית:

| סוג | דוגמה | מה המערכת עושה איתו |
|---|---|---|
| הכנסה קבועה | משכורת, קצבאות | צופה שתיכנס שוב |
| הכנסה משתנה | החזר מס, בונוס | סופרת כשנכנסה, לא מבטיחה שתחזור |
| הוצאה קבועה | שכר דירה, ביטוח, מנויים | נשמרת מראש בתחזית ויורדת ממה שנשאר להוציא |
| הוצאה משתנה | סופר, מסעדות, דלק | **זה מה שבשליטתכם** |
| הפקדה לחיסכון | הוראת קבע לפיקדון | יורדת ממה שנשאר להוציא, אבל נספרת כהישג ולא כהוצאה |
| העברה | חיוב כרטיס אשראי בבנק, העברה בין חשבונות שלכם | לא נספרת בשום סיכום — כדי שלא תיספר פעמיים |
| לא נספר בתזרים | פירעון משכנתא חד-פעמי, משיכה מהשקעה | כסף אמיתי שלא שייך לקצב החודשי — מוצג, אבל לא מעוות את התחזית |

**3. שתי תצוגות לאותו כסף.** קנייה באשראי ב-5 בחודש יורדת מהבנק רק ב-10 בחודש הבא. ב**תצוגה החשבונאית** ("מה הוצאתי") היא נספרת ביום הקנייה; ב**תצוגת המזומן** ("מה יהיה בבנק") ביום החיוב. המסכים אומרים תמיד באיזו תצוגה הם.

**4. חיובי אשראי שעוד לא ירדו.** כסף שכבר הוצא בכרטיס אבל עוד לא ירד מהבנק. זו הסיבה שיתרת הבנק נראית טוב יותר מהמצב האמיתי, ולכן המערכת מציגה אותו במפורש.

**5. פריסה.** בונוס שנתי או תשלום מראש לכמה חודשים נכנסים בפעם אחת. אם סופרים אותם כולם בחודש שבו נכנסו, החודש הזה נראה מצוין והבאים נראים כמו קריסה. פריסה מחלקת סכום כזה על פני כמה חודשים **בתצוגה החשבונאית בלבד** — היתרה בבנק לא משתנה.

## החודש

![המסך הראשי](images/home.png)

- **המספר הגדול** — **כמה נשאר להוציא** על הוצאות משתנות עד סוף המחזור, ומתחתיו כמה זה ליום. *זו לא יתרת הבנק.*
- **מתחת למספר** — העודף או הגירעון הצפוי בסוף המחזור, קצב ההוצאות המשתנות מול אותה נקודה במחזור הקודם (כשהוא חריג), וכמה באשראי עוד ירד מהעו״ש.
- **התווית ליד הכותרת** ("כל החשבונות מעודכנים" / "הערכה חלקית — חסרים נתונים") — כמה אפשר לסמוך על המספר. לחיצה מובילה לבדיקת הנתונים.
- **"מה עומד מאחורי הסכום הזה?"** — פותח את המשוואה המלאה, וכל שורה בה מקשרת לתנועות שמרכיבות אותה.
- **הצעד הבא** — נקבע לפי הנתונים: צפי למינוס בעו״ש, בעיה בנתונים, קצב הוצאה גבוה, או החיוב הגדול הבא.
- **חיובים והכנסות קרובים** — ההכנסות וההוצאות הקבועות הבאות, עם "היום" / "מחר" או תאריך.
- **החלפת מחזור** (למעלה משמאל) — חזרה אחורה עד 36 מחזורים.

**"יתרה בעו״ש ופירוט החישוב"** מוביל למסך המפורט:

![פירוט החודש](images/month-details.png)

- **נשאר להוציא** — כמה עוד אפשר להוציא על הוצאות משתנות במחזור, אחרי ההוצאות הקבועות והחיסכון. *זו לא יתרת הבנק.*
- **יתרה בעו״ש בפועל** — מה שדווח בעדכון האחרון של כל חשבון, עם מועד העדכון.
- **יתרה בעו״ש לאורך המחזור** — גרף יום-אחרי-יום: קו מלא עד היום, תחזית מהיום. אפשר לעבור עליו עם העכבר או עם **החצים במקלדת**, ויש **תצוגת טבלה** עם כל הערכים. משולשים מסמנים כסף שנכנס (▲) ויוצא (▼), ואזור אדום מסמן סכנת מינוס.
- **לאן הלכו ההוצאות המשתנות** ו**מגמות** של 12 חודשים — האם חודש חריג הוא מקרה או מגמה.

## תכנון

![תכנון](images/planning.png)

- **מה עוד צפוי במחזור** — כל ההכנסות וההוצאות הקבועות שעוד לא הגיעו.
- **תכנון עד סוף המחזור** — סליידר: "אם אוציא X ליום, כמה יישאר?", עם **נקודת האיזון** מסומנת.
- **קצב ההוצאה** — ההוצאות המשתנות מתחילת המחזור, מול אותה נקודה במחזור הקודם.
- **הוצאות קבועות, פריסות ותשלומים** —
  - **תשלומים**: כל רכישה בתשלומים, כמה שולם מכמה, ובעיקר **לוח השחרור** — כמה כסף מפסיק לרדת בכל חודש.
  - **חיובי אשראי שעוד לא ירדו** לפי כרטיס ומועד חיוב.
  - **פריסות** פעילות, עם אפשרות להוסיף הערה.

## תנועות

![תנועות](images/transactions.png)

- התנועות **מקובצות לפי יום**, עם סיכום היום (בלי חיובי אשראי מרוכזים, שכבר נספרו כקניות). **מיון** לפי תאריך או סכום. סיכום "נכנס / יצא" לא כולל העברות פנימיות.
- **חיפוש** לפי שם בית עסק, ו**בחירת חודש**. **מסננים**: חשבון, קטגוריה, טווח תאריכים, מצב (הושלם / בהמתנה), טווח סכומים, והשפעה על התזרים.
- **בחירה מרובה** — מסמנים כמה תנועות, בוחרים קטגוריה (או "הסרת סיווג") ומסווגים את כולן יחד. לפני השינוי מוצגת **תצוגה מקדימה** של מה ישתנה.
- **לחיצה על תנועה** פותחת את הפרטים:
  - **קטגוריה** — שינוי ידני *נועל* את התנועה, וחוקים אוטומטיים לא ידרסו אותו.
  - **למה סווגה כך** — ידנית, לפי איזה חוק, או ללא סיווג.
  - **הערה** בשלוש רמות: לתנועה הזו בלבד, **לכל התשלומים** של אותה רכישה (כולל עתידיים), או **לכל התנועות מבית העסק** (גם עתידיות). ההערה הספציפית גוברת.
  - **פריסה על פני חודשים** — עם תצוגה של הסכום לחודש והחודשים המדויקים לפני השמירה.
  - **"להחיל על כל תנועה מבית העסק"** — יוצר חוק, אחרי תצוגה מקדימה של כמה תנועות יסווגו.
  - **חוקים שמתאימים לתיאור** — וקישור לעריכתם.

## לאן הכסף הולך

![לאן הכסף הולך לפי קטגוריות](images/breakdown.png)

לפי **חודש קלנדרי**. למעלה — כשהמחזור הנוכחי מתחיל בחודש הזה, העודף או הגירעון הצפוי בסוף המחזור (אותו מספר כמו במסך החודש) ומרכיביו. מתחת — כרטיס לכל קטגוריה: כמה יצא, כמה תנועות, איזה חלק מההוצאות, ומצב התקציב **בשקלים** ("נותרו 26 ₪", "מעל התקציב ב-1,027 ₪") ולא באחוזים. לחיצה על קטגוריה מציגה את התנועות שלה באותו מקום. בהמשך: ההכנסות, ההפקדות לחיסכון וסיכום התקציבים.

## לטיפול

תור עבודה שאפשר **לסיים**. מספר הפריטים מופיע על הכפתור "לטיפול" בראש המסך, והמסך נפתח בלשונית הראשונה שיש בה עבודה. שלוש לשוניות:

**בדיקת נתונים** — האם המספרים שלמים:
- **התאמת חיובי אשראי**: לכל מחזור חיוב, האם הסכום שירד מהבנק שווה לסכום הקניות בכרטיס. אי-התאמה מצביעה על תנועות חסרות או על כרטיס שלא מחובר.
- **ממצאים**: בנק או כרטיס שהפסיק להתעדכן, חברת אשראי שמחייבת את הבנק אבל לא מחוברת, חיוב אשראי שנספר כהוצאה ועוד. לכל ממצא — ראיות, קישור לתנועות, ואפשרות לסמן "נבדק" עם הסבר. ממצא שסומן לא חוזר, אלא אם משהו השתנה.

**לסיווג** — כרטיס אחד בכל פעם, החשובים קודם:

![תור הסיווג](images/review.png)

- בוחרים קטגוריה בלחיצה (ההצעות מסוננות לפי כיוון התנועה).
- **"להחיל על כל תנועה בשם הזה"** — יוצר חוק, וכל התנועות העתידיות מבית העסק יסווגו לבד. כך כל בית עסק דורש החלטה **אחת**.
- תנועה גדולה מאוד בבנק (25,000 ₪ ומעלה, למשל העברה להשקעה או משכורת עם בונוס) לא מסווגת אוטומטית לפי הגודל שלה: היא מופיעה ב**בדיקת נתונים** כתנועה גדולה שממתינה להחלטה — משכורת, העברה פנימית, חיסכון או "לא נספר בתזרים".
- תנועה בהמתנה מסומנת: אם תחכו יום-יומיים, השם הסופי שלה עשוי להשתנות.

**תובנות** — בדיקות דטרמיניסטיות, לא ניחושים: **חיוב כפול** (אותו סכום, אותו בית עסק, תוך 3 ימים), **מנוי שהתייקר**, **חיוב חריג** (פי 2.5 מהרגיל), **בית עסק חדש** (גם סימן אזהרה להונאה), **קטגוריה מול עצמה** בחודשים קודמים, ו**תשלומים שמסתיימים**. אפשר לסמן כל תובנה כמועילה, לא רלוונטית, טופלה או "הזכר לי בעוד שבוע".

## תפריט הניהול

כפתור ☰ בפינה פותח את המסכים שמשתמשים בהם פחות:

### חשבונות וחיבורים
כל בנק וחברת אשראי, החשבונות שלהם, מתי עודכנו, כמה תנועות, היתרה והסכום שממתין לחיוב. מכאן **מוסיפים חיבור**, **מעדכנים נתונים** (לכולם או לאחד), מעדכנים פרטי התחברות, משנים שם (כפתור העיפרון), קובעים **יום חיוב** לכרטיס, ומסמנים חשבון כ**רדום** (לא יתריע על חוסר עדכון) או **סגור** (נשאר בהיסטוריה, לא נכנס לתחזית). כשעדכון נכשל, מופיע כרטיס בעברית לכל בנק עם הסיבה וכפתור לתיקון; הלוג הטכני מקופל מתחת.

### הכנסות והוצאות קבועות
![הכנסות והוצאות קבועות](images/recurring.png)

ההכנסות וההוצאות הקבועות. רובן **מזוהות אוטומטית** מההיסטוריה (כולל חשבונות דו-חודשיים כמו חשמל ומים), ואפשר גם להוסיף ידנית. לכל אחת: סכום צפוי, יום בחודש, תדירות, תוקף (מתאריך / עד תאריך), התאריך הבא, ומצב — פעילה, עתידית, פגה, או "לא נראתה לאחרונה" (ואז אפשר לאשר שהיא עדיין בתוקף).

### קטגוריות ותקציבים
![קטגוריות](images/categories.png)

הקטגוריות מקובצות לפי סוג. לכל אחת: שם, צבע ואייקון (אפשר לערוך), סוג ו**תקציב חודשי** (לא חובה, רק להוצאות ולחיסכון). **שינוי הסוג משנה את התחזית** — זו ההחלטה החשובה במסך הזה. בהתקנה חדשה נטענות אוטומטית 19 קטגוריות וחוקים לרשתות המוכרות בישראל.

### חוקי סיווג
![חוקים](images/rules.png)

חוק = "אם התיאור מכיל X, הקטגוריה היא Y". אפשר גם ביטוי רגולרי (עם הגנה מפני ביטויים שיתקעו את המערכת). **עדיפות** גבוהה מנצחת. לפני שמירה מוצגת **תצוגה מקדימה**: כמה תנועות יתאימו, כמה מהן נעולות ידנית, וכמה מתנגשות בחוק אחר — ואפשר לסווג באותו שלב גם את התנועות הקיימות שעדיין בלי קטגוריה. תנועה שסווגה ידנית לעולם לא נדרסת.

**הצעות סיווג ממודל מקומי** — אם מותקן Ollama, מודל מקומי מציע חוקים לבתי העסק שנשארו, ואתם מסמנים את מה שנכון.

### היסטוריית שינויים
כל סיווג, חוק או שינוי קטגוריה נרשם, ואפשר **לבטל** אותו — כל עוד הנתונים לא השתנו מאז. אחרי כל פעולה מופיעה גם הודעת "בטל" קצרה בתחתית המסך.

### הגדרות
![הגדרות](images/settings.png)

- **יום פתיחת המחזור.**
- **התראות בטלגרם** — חיבור בוט, נמענים נוספים (למשל בן/בת זוג), רמת פירוט, ושליחת סיכום לבדיקה.
- **גיבוי מוצפן** — תיקיית יעד וכמה גיבויים לשמור.
- **מראה** (בתפריט הניהול): בהיר, כהה, או לפי המכשיר.

![מצב כהה](images/home-dark.png)

## סיכומים בטלגרם

איך יוצרים את הבוט ומחברים אותו, צעד אחרי צעד: [מדריך ההתקנה ← סיכומים בטלגרם](INSTALL.md#סיכומים-בטלגרם).

המשימה היומית שולחת את הסיכום שמתאים לתאריך:

| מתי | מה |
|---|---|
| **1 בחודש** | סיכום חודשי — עודף או גירעון, מול החודש הקודם ומול הממוצע, לאן הלך הכסף, מה בלט באותו חודש, ותשלומים שמסתיימים |
| **יום ראשון** | סיכום שבועי — הוצאות משתנות מול שבוע רגיל, הקבועות בנפרד, לאן הלכו המשתנות, תובנות, מצב המחזור והשבוע הקרוב |
| **שאר הימים** | יומי — שתיים עד ארבע שורות: אתמול מול התקציב היומי, כמה נשאר להוציא במחזור, והקצב רק כשהוא חריג. חיוב שיורד היום או מחר, תקציב שנחצה אתמול, חשבון שלא התעדכן, חיוב חשוד או צפי למינוס — רק ביום שהם רלוונטיים |

בימים רגילים ההודעה היומית מגיעה **בלי צליל**; צליל רק כשיש משהו לטפל בו.

שלוש רמות פירוט: **מלא** (שמות בתי עסק), **בלי שמות** (רק קטגוריות) ו**מינימלי** (רק סכומים). הערוץ יוצא בלבד — אי אפשר לשלוט במערכת מטלגרם.

## פקודות טרמינל

ארגומנטים נכתבים כמילים אחרי `--`, לא כדגלים: `npm run scrape -- max`.

| פקודה | מה היא עושה |
|---|---|
| `npm run api` | מפעיל את השרת והממשק (http://127.0.0.1:3010) |
| `npm run scrape` | עדכון נתונים מכל הבנקים וחברות האשראי שהגיע זמנם · `-- max` רק אחד · `-- force` כולם |
| `npm run login -- <חברה>` | התחברות ידנית חד-פעמית בדפדפן גלוי (לאתגרי SMS) |
| `npm run accounts` | רשימת חיבורים · `-- add` / `-- update` / `-- remove` |
| `npm run check-config` | בודק את קובץ ההגדרות בלי להציג סיסמאות |
| `npm run audit` | בדיקת ספירה כפולה של חיובי אשראי וכיסוי הנתונים |
| `npm run inspect` | דוח איכות נתונים אחרי חיבור חשבון אמיתי |
| `npm run check:consistency` | מוודא שהסיכומים תואמים בין המסכים |
| `npm run rules:preset` | מחיל מחדש את הקטגוריות והחוקים המוכנים |
| `npm run backup` | גיבוי עכשיו · `-- init` / `-- list` / `-- verify` / `-- restore <file>` |
| `npm run notify` | שולח את סיכום היום בטלגרם · `npm run notify:preview -- monthly` מציג בלי לשלוח |
| `npm run schedule:install` | רישום המשימות היומיות · `:status` / `:check` / `:remove` |
| `npm run secure` / `secure:check` | הקשחה ובדיקת מצב האבטחה |
| `npm run history:prune -- 12` | תצוגה של מחיקת תנועות ישנות מ-12 חודשים · `apply` לביצוע |
| `npm run reset` | מוחק חשבונות ותנועות ושומר קטגוריות וחוקים · `-- all` גם קטגוריות · עם חשבונות אמיתיים דורש גם `force` |
| `npm run seed` | נתוני הדגמה (מסרב אם יש חשבון אמיתי) |
| `npm run llm:bench` | מודד את דיוק המודל המקומי על הסיווגים הקיימים |
| `npm run git:safe-check` | לפני פרסום קוד: סודות ונתונים אישיים בקבצים שיתפרסמו |
